# 自動測試

遊戲仍是無需建置的靜態網站；測試工具只供開發時使用，需要 Node.js 20 以上。

```sh
npm ci
npx playwright install chromium
npm test
```

測試以本機 HTTP 服務啟動網站，檢查三關通關與解鎖、條件成立及略過的回饋、重複行動次數與錯誤回饋、重載與重新遊玩、任務間草稿、執行中切換任務、目前執行行的標示與捲動、鍵盤導航、編輯後重新執行、儲存讀取或寫入失敗、多分頁進度、窄版地圖、中途重設、Chromium 輔助科技樹中的地圖結構，以及模擬觸控的指令插入和單步。每項測試使用獨立瀏覽器環境，不會更動玩家的實際存檔。

通關測試另檢查導航門後仍有指令時，再次單步會從起點開始新的一次執行。

場景測試檢查小芽移動、收集光種後的能量顯示與重設，並在桌面與窄視窗測量地圖四邊是否完整顯示。

探索測試檢查三關的可選回聲、通關後的故事、重設狀態及不探索時仍可通關；小螢幕通關畫面另檢查兩個操作按鈕都位於場景內。

GitHub Actions 在推送 `main` 後分別使用 Chromium、Firefox 和 WebKit 執行測試，通過後才發布 Pages；Firefox 不支援 Playwright 行動裝置模擬，因此略過觸控模擬，輔助科技樹檢查則只在 Chromium 執行。自動測試不取代實際玩家、行動裝置或輔助科技測試。

Pages 部署第一次失敗時會等待 15 秒重試一次；重試仍失敗則整個部署工作失敗，以免掩蓋持續性問題。
