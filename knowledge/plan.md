# 程式學習遊戲：願景與路線圖

## 願景

打造一款以遊戲體驗為核心的 Web 應用，讓玩家在探索、冒險與解謎的過程中自然學會程式。程式概念應成為玩家解決遊戲世界問題、操控角色或破解機關的工具；玩家首先感受到的是一款好玩的遊戲，而不是課程或測驗。

## 目前狀態

**早期原型階段。** 已選定初版玩家、JavaScript 入門範圍、科幻探索題材與靜態 Web 技術；正在製作第一段可玩的程式解謎原型。核心設計仍需新手玩家測試驗證。

## 路線圖

- [x] 確立設計優先級：以遊戲體驗為主，避免教學感削弱遊戲感。
- [x] 確立初步體驗方向：透過劇情、探索、角色操控與解謎，讓程式概念融入玩法。

## 設計原則

- 玩家在遊玩中學習，避免把關卡做成換皮測驗或課程章節。
- 程式概念要對遊戲世界產生清楚、可理解的影響。
- 透過挑戰、探索、回饋與逐步解鎖維持遊戲動機。
- 教學提示應在玩家需要時提供，並支持嘗試與修正。
