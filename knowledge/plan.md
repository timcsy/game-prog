# 程式學習遊戲：願景與路線圖

## 願景

打造一款以遊戲體驗為核心的 Web 應用，讓玩家在探索、冒險與解謎的過程中自然學會程式。程式概念應成為玩家解決遊戲世界問題、操控角色或破解機關的工具；玩家首先感受到的是一款好玩的遊戲，而不是課程或測驗。

## 目前狀態

**可玩原型階段。** 六段相連任務從依序執行、受限 `repeat` 和 `if` 感測，延伸到多組光閘，以及推動光晶啟動底座；各關也有可選的星球回聲。遊戲畫面與核心體驗仍需新手玩家測試驗證。

## 路線圖

### 新方向：讓玩家感覺自己正在冒險

使用者希望看到的是**完整的遊戲畫面，而非有遊戲裝飾的網頁**，並且希望遊戲體驗更豐富、好玩。遊戲世界應是主要畫面，任務資訊與程式操作應像遊戲內的介面，而不是文章標題、網站導覽和並排表單。程式繼續作為探索與解謎的工具；「是否好玩」仍要透過初學者實際試玩驗證。

- [ ] 重塑為完整遊戲畫面：以可視範圍內的星球場景為主體，把任務狀態、關卡切換和程式指令做成遊戲內 HUD／控制介面；移除文章式大標、網站導覽和開發連結等遊玩時的網站元素，而不只是改變配色或替原有網頁加裝飾。
- [ ] 為不同螢幕設計遊戲操作：桌面同時看見場景與控制台，窄螢幕可方便地在場景和程式操作間切換或查看；保留鍵盤、螢幕閱讀器語意、減少動態效果及可讀文字。
- [ ] 強化冒險循環：讓玩家清楚感受到出發、探索、取得光種、點亮導航門及前往下一區域，並以角色反應、世界變化和通關演出回應玩家行動。
- [ ] 設計更有趣的關卡變化：在既有指令範圍內嘗試不同地形、路線選擇和可觀察的機關，讓程式用來解決遊戲世界的問題；逐步調整難度並保留可重試的低壓體驗。
- [ ] 增加探索與進展的動機：評估能反映玩家旅程的發現、解鎖或小獎勵，避免只增加沒有玩法意義的分數；設計與實作後觀察玩家是否想繼續。
- [ ] 以初學者試玩驗證新版是否更有趣、目標是否清楚，以及程式操作是否仍容易理解；依觀察迭代，而非把視覺更新當成遊戲體驗已獲證實。

先以現有三關為基礎分階段實作和測試，不預先假定新增語法或關卡數量；每一階段保留現有進度、鍵盤操作和靜態發布能力，並在完成後記錄經驗與適用範圍。

## 設計原則

- 玩家在遊玩中學習，避免把關卡做成換皮測驗或課程章節。
- 程式概念要對遊戲世界產生清楚、可理解的影響。
- 透過挑戰、探索、回饋與逐步解鎖維持遊戲動機。
- 教學提示應在玩家需要時提供，並支持嘗試與修正。
